## 报价结构
- **基础套餐**（四档：入门/标准/舒适/豪华）：智能开关面板、窗帘电机、智能网关、人体/门窗传感器、燃气/水浸报警。
- **加购三款**（勾选才计入合计，不混套餐）：灯具、网络、中控屏。

## 手机用法
1. 用手机浏览器打开网址
2. 菜单 →「添加到主屏幕」
3. 桌面点图标直接打开，断网也能报价

参数会自动存在本机（localStorage），下次打开还在；换客户点「✕ 清空重来」。

## 技术
纯静态单页：index.html + manifest.webmanifest + sw.js（Service Worker 离线缓存）+ icons。
无后端、无数据库、无账号，GitHub Pages 直接托管。
